What is ASAP NeuroScan?

ASAP NeuroScan is a web-based application designed to assist in the detection of brain tumours from MRI scans using deep learning. The system analyzes uploaded MRI images and provides a predicted tumour class along with a confidence score.

Why We Built This

Brain tumour diagnosis often requires expert interpretation and can be time-consuming. This project explores how artificial intelligence can support medical analysis by providing faster, visual, and explainable insights in academic and research settings.

How It Works

  • User uploads an MRI image
  • The image is processed on the backend using a trained model
  • A tumour prediction with confidence is generated
  • Grad-CAM visualization highlights influential regions

Understanding the Output

The confidence score indicates how certain the model is about its prediction. The Grad-CAM image helps visualize which areas of the MRI scan influenced the model’s decision, improving transparency and interpretability.

Our Team
